# 参考实现分析

## 保留的设计基准

- 纸张色背景、深墨色正文、橙色问题强调、绿色/蓝色数据状态，圆角卡片与细边框形成清晰但克制的层级。
- 首屏同时给出论文身份、研究问题、摘要式解释和一个核心证据数字；随后进入一分钟速读。
- 主体不是论文目录复刻，而是“问题 → 诊断 → 方法 → 公式 → 训练 → 实验 → Related Work → 出处”的知识路径。
- 论文原图、派生流程图、比较图、关系图与正文共同承载信息；Evidence 浮卡保留关闭与跳转两个动作。
- 桌面端粘性导航、阅读进度、深浅主题；移动端导航可横向滚动，宽表和关系图具有滚动提示。
- 公式中的变量直接可交互；图表有读屏名称、键盘操作和 reduced-motion 适配。

## 当前样例的工程问题

- 单个 HTML 同时包含论文内容、Base64 图片、Evidence Registry、实验数据、Related Work 元数据、组件 HTML 和交互代码。
- 多处直接出现论文 ID、论文标题、固定页码、数据集名称及 AWM 专属变量，无法替换输入后自动重用。
- 页面结构通过后置脚本追加和覆盖，难以用 Schema 校验，也难以定位内容重复的来源。
- 部分 Evidence 是人工整理文本，缺少稳定的 PDF block/字符区间，无法机器证明“连续原文”。
- Related Work 的部分入口使用搜索页兜底；需要把“元数据已核验”和“入口可访问”变成独立状态。
- 样例具备良好交互，但没有可重复的输入 → IR → Page Model → HTML 构建链和跨论文测试。

## 模板化结论

- 保留视觉 token、信息密度、卡片行为和章节阅读节奏。
- 将论文身份、速读卡、Evidence、原图、公式、派生图、实验矩阵和 Related Work 图全部变成数据组件。
- 页面生成器只识别组件类型和通用字段，不识别论文标题、arXiv ID、数据集或方法名。
- AWM 冻结页只参与视觉回归；新模板和源码不得引用其专属值。

## 回归指标

- 首屏在 1440×900 下能同时看到论文身份、核心问题和核心证据。
- 360 px 宽度无正文横向溢出；宽表/关系图只能在标记区域内横向滚动。
- 所有交互元素可用 Tab 聚焦，以 Enter/Space 激活；弹卡关闭后焦点回到触发点。
- 深浅主题对比度、reduced-motion、图片替代文本、SVG title/desc 和跳过链接均通过检查。
- 任意 Evidence 的展示文本、页码和 PDF 跳转目标都能从 IR 重建。
