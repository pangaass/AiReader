# 从科研海报与 PPT 设计 Paper Visualizer

日期：2026-09-04

## 1. 结论

方案可行，而且方向正确。科研海报和学术 PPT 已经完成了两类重要的信息设计工作：

- 海报擅长把整篇论文压缩成一页，提供栏目选择、视觉层级、图文比例和结果优先级。
- PPT 擅长把论文组织成阅读序列，提供叙事节奏、逐步展开和“一页一个核心问题”的表达方式。
- Paper Visualizer 可以在两者之上增加交互、原文定位、证据追溯、按需展开和跨章节关联。

因此，产品不应直接复制某张海报或把 PPT 页面纵向堆叠，而应抽取它们背后的信息组织规律。推荐的定位是：

> 海报式总览 + PPT 式叙事 + 可验证的交互式深读。

当前路线不再拆成串行的“两步”：对每个 Paper–PPT/Poster pair，多个 LLM Agent 并行抽取展示侧与论文 PDF，识别作者选择、总结和组织了哪些文本、公式、数字、引用及讲解结构；图片和表格当前不展开内部内容，只和论文 PDF 中的 Figure/Table、caption、页码与坐标对应。独立 Alignment Judge 随后比较两侧结果，Meta-Harness、TextGrad 类方法或自定义 Optimizer 根据跨 pair 误差持续优化只输入 PDF 的 Paper Extraction Harness；同一次候选比较期间冻结 Presentation 输出，避免弱监督目标漂移。

详细目标、过滤规则和实施阶段见：[Paper Visualizer 当前研究目标与数据处理流程](CURRENT_RESEARCH_GOAL_AND_DATA_PIPELINE.md)。

### 2.1 第一梯队：核心参考

| 资源 | 学术来源与规模 | 主要价值 | 局限 |

### 2.3 跨学科扩展资源

目前没有一个现成 Benchmark 同时满足“大规模、论文—海报/PPT 成对、跨学科、许可统一”。跨学科部分需要自行构建。

- [Zenodo Poster](https://zenodo.org/search?q=resource_type.type%3Aposter)：2026-09-04 查询约38,385条记录。
- [Zenodo Presentation](https://zenodo.org/search?q=resource_type.type%3Apresentation)：同期约92,629条记录。
- [Figshare](https://figshare.com/browse)：官方支持 Poster 和 Presentation 类型，公开元数据与文件可以通过 API 获取。
- F1000Research：可补充医学、生命科学和健康研究，SciPostLayout 已整理其中一部分。
- OpenAlex、Crossref、Unpaywall、PubMed Central：用于把海报或 PPT 按 DOI、标题、作者连接回论文全文。

Zenodo 和 Figshare 数量很大，但混有宣传海报、课程 PPT、项目介绍和非学术材料，必须经过学术性、配对关系、文件质量与许可过滤，不能直接作为 Gold。

## 3. 海报、PPT 与 Paper Visualizer 的关系

| 载体 | 最擅长解决的问题 | 可迁移设计 | 不宜直接照搬的部分 |
|---|---|---|---|
| 科研海报 | 一眼看懂论文贡献 | 总览、栏目分区、结果优先、关键图放大、有限文字 | 固定大画布、极高信息密度、依赖读者自由扫视 |
| 学术 PPT | 按顺序讲清研究故事 | 动机→方法→实验→结论的叙事、渐进披露、单屏单重点 | 强制线性播放、内容被切碎、脱离讲者后信息可能不足 |
| Paper Visualizer | 快速理解后按兴趣深入并验证 | 总览与深读双层结构、可展开内容、证据跳转、跨栏目联动 | 不应退化为海报截图、PPT 播放器或卡片瀑布流 |

最重要的区别是：海报和 PPT 通常只展示结论，而 Visualizer 必须让结论回到原文证据。因此所有借鉴都要经过 Evidence 层，而不是只模仿视觉形式。

## 4. 推荐栏目结构

### 4.1 第一层：海报式总览

用户进入页面后，应在一屏到两屏内看到：

1. 研究问题与现实意义。
2. 一句话核心贡献。
3. 方法总览图。
4. 最关键的两到四项结果。
5. 适用边界或主要局限。

这一层借鉴海报的信息压缩，但每个结论、图和数值都可以点击定位原文。

### 4.2 第二层：PPT 式叙事

推荐顺序不是机械复制论文目录，而是：

1. 为什么需要这项研究。
2. 现有方法缺少什么。
3. 本文提出什么。
4. 方法如何运行。
5. 实验怎样验证主张。
6. 哪些结果最重要。
7. 为什么有效、何时失效。
8. 与相关工作相比改变了什么。

每个栏目应表达一个问题，避免把所有栏目统一渲染成同一种卡片。

### 4.3 第三层：Visualizer 独有的交互深读

- 点击结论，展开支持它的实验、表格和原文。
- 点击方法步骤，定位论文中的方法段落、公式或原图。
- 点击图表数据，显示实验条件和正文解释，而不只是重复数值。
- 点击公式变量，显示变量定义及首次出现位置。
- 在“总览、方法、实验、局限”之间建立语义跳转，而不是只提供上一页、下一页。
- 提供“只看核心”“按论文顺序”“按问题探索”三种阅读路径。

## 5. 不同学科不能使用同一套固定栏目

应保留统一的 Paper IR 和 Evidence 协议，但允许栏目结构随论文类型变化。

| 学科或论文类型 | 更合适的栏目顺序 |
|---|---|
| 计算机与工程 | 问题 → 系统输入输出 → 方法架构 → 数据集/指标 → 结果 → 消融 |
| 医学与生命科学 | 临床问题 → PICO/样本 → 干预或实验流程 → 主要终点 → 效应与不确定性 → 局限 |
| 化学与材料 | 材料/反应体系 → 制备条件 → 结构或机理 → 表征方法 → 性能 → 稳定性 |
| 物理与地学 | 现象 → 假设/模型 → 观测或模拟 → 参数条件 → 结果与误差 → 解释 |
| 数学与理论 | 定义 → 假设 → 核心定理 → 证明思路 → 推论 → 适用边界 |
| 社会科学 | 研究问题 → 理论机制 → 数据与样本 → 识别策略 → 结果 → 稳健性与外部效度 |
| 人文学科 | 核心论点 → 材料来源 → 论证链 → 关键例证 → 竞争性解释 → 历史语境 |

系统应先识别论文类型，再选择栏目和组件；不能让“方法架构图”和“消融实验”成为所有学科的强制项。

## 6. 建议建立的 Benchmark

### 6.1 四类任务

1. **内容选择**：能否从论文中选出适合海报/PPT展示的核心问题、方法、图表、结果和局限。
2. **叙事规划**：能否把内容组织成合理栏目与阅读顺序，而不是复刻章节目录。
3. **视觉与交互表达**：能否为不同关系选择流程图、对比表、时间线、实验蓝图或原图展示。
4. **证据一致性**：每个结论、数值、公式和引用是否能准确回到论文原文。

### 6.2 评测指标

- 内容正确性与幻觉率。
- 核心贡献、关键结果和局限的覆盖率。
- 原文 Evidence、页码、图表和公式定位准确率。
- 栏目顺序与论文类型的适配度。
- 图文层级、字号、拥挤度和整体可读性。
- 阅读者完成 PaperQuiz 或任务问答后的准确率与用时。
- 交互是否帮助理解，而不是只增加点击次数。

### 6.3 跨学科测试集

建议先构建一个约1,000篇的人工审核测试集，每个方向约100篇：

- 医学与临床研究
- 生命科学
- 化学与材料
- 物理与天文
- 地球与环境科学
- 工程技术
- 数学与理论
- 社会科学与经济学
- 心理与教育
- 人文与历史研究

优先保留 CC-BY 或 CC0 内容，并为每篇论文保存论文 PDF、目标海报或 PPT、栏目映射、关键视觉元素、原文证据和阅读问题。训练数据可以大而弱标注，测试数据必须小而严格。

## 7. 实施优先级

- **P0：借鉴结构**。从海报/PPT中学习栏目、内容优先级和图文比例，生成海报式总览与 PPT 式叙事。
- **P0：保持证据门禁**。所有关键内容继续绑定 Paper IR、Evidence ID、页码和坐标。
- **P1：论文类型路由**。先识别学科与论文类型，再选择栏目模板和视觉语法。
- **P1：建立双层页面**。默认展示核心故事，用户点击后展开实验条件、细节和原文。
- **P1：建立 PaperQuiz**。用论文生成问题，再比较读原文、读海报、读 Visualizer 后的回答表现。
- **P2：学习视觉风格**。从大量海报和 PPT 中提取版式先验，但不直接复制受版权保护的模板。
- **P2：跨学科 Gold**。从 Zenodo、Figshare 和 F1000Research 建立人工审核的平衡测试集。

## 8. 主要风险

- 海报与 PPT 是作者对论文的一种解释，不是唯一正确的栏目结构。
- 计算机领域数据过多，容易让系统把所有论文都表达成“任务—模型—数据集—指标”。
- 图片相似度只能判断外观，无法判断结论是否正确。
- 自动生成的训练指令不能等同于人工设计 Gold。
- 同一篇论文、海报和 PPT 可能具有不同许可，必须分别记录。
- 视觉上更漂亮不代表更容易理解，应使用阅读问答、定位时间和人工偏好共同评估。

## 9. 推荐决策

当前项目可以采用以下组合：

- 用 Paper2Poster 的评测思想定义海报式总览质量。
- 用 DOC2PPT 和 SciDuet 学习叙事顺序与内容压缩。
- 用 SciPostGen、PosterSum 和 SciPostLayout 学习视觉布局与栏目分布。
- 保留现有 Evidence-first 架构，把交互建立在原文证据之上。
- 单独建设跨学科测试集，避免用计算机论文上的良好表现代表通用科研阅读能力。

这一路线不是把 Paper Visualizer 变成“自动海报生成器”或“自动 PPT”，而是利用两类成熟载体的表达经验，构建更适合屏幕阅读、探索和核验的第三种论文媒介。
